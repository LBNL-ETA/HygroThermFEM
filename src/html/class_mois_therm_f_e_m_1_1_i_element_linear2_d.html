Detailed Description

IElementLinear2D.

Class that handles creation of conductance and capacitance matrices in linear 2D world. This class will be used by multiple governing equations since basis of matrix creation are identical with only difference in what coefficients are passed

IElementLinear2D.

Evaluating material influence in every node (This is important to know when calculating water content).


Form triangle of nodes. node1 is in center and angle is calculated at that node.

Weighting coefficient depends on angle that is form by nodes next to node1. That coefficient is fraction of full circle.
Node will have possibility to calculate certain properties that will be material dependent.
