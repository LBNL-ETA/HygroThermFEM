Detailed Description

Supports multiplication of between matrix and vector in differential equations.

Differential equations sometimes have mutliplication between matrix of that is function of certain node properties and vector of some node property as well. For example, heat transfer equation have [H]*{vapor content} that needs to be evaluated. This structure is used to support matrix-vector pair that will be used in differential equations creation.
