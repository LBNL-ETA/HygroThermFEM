Detailed Description

QLECapacitance2D.

Class to handle capacitance matrix in global coordinate system. Equation is derived from C * Du/Dt where u is state variable.

Integrator is acutally calculating simple integration matrix Ksi,i * Ksi,j which is used to calculate capacitance (or mass) matrix. It is more important to put this matrix at correct place in matrix system of equations.
