◆ R_Vector()

virtual std::vector<double> MoisThermFEM::IBCLinear2D::R_Vector ( ) const
pure virtual

Every boundary condition will return matrices and vectors. There are two type of matrices. First one is called H matrix and will include sum of all matrices that do not have first derivative of coefficients. Second one is delta H matrix that is based on coefficients derivative. Reason for keeping them separate is that matrix equation for non-linear case need to know what matrices are coming from coefficients derivative, because they will be on left hand side, next to unknown.

Implemented in MoisThermFEM::MoistureBC, MoisThermFEM::BlackBodyRadiationBC, MoisThermFEM::FluxBC, and MoisThermFEM::ConvectionBC.
