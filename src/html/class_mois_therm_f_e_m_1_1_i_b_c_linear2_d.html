Detailed Description

Interface class for boundary conditions in linear 2D finite elementsCreator.

Any new boundary condition created in MoisThermFEM engine must be inherited from this class. It provides necessary interface for rest of the program to be able to communicate with boundary condition. In finite element world, every boundary condition will return matrix and vector. Matrix is what stand next to state variable (unknown) that program is seeking solution.
