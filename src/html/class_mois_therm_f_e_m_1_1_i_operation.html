Detailed Description

template<class T, class U>
class MoisThermFEM::IOperation< T, U >

IOperation.

It is used to support operation with functions.

Functions that are child of IValue are used directly in differential equations. Those functions can be stacked with ordinary operations. This class is used to support those operations.
